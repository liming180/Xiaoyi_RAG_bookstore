### uvicorn 0.54.0

只在 `app/api.py:299-303` 的 `main()` 里局部 import：

```python
def main() -> None:      # pragma: no cover - 便捷入口
    import uvicorn

    port = int(load_config().get("port", 8765))
    uvicorn.run(app, host="127.0.0.1", port=port)
```

**为什么局部 import**：`tools/selfcheck.py` 与 `frontend/test/**/*.spec.ts` 之外的所有调用方（自检、批量脚本）
都只需要 `app` 对象，不需要真的起服务器；把 uvicorn 放进函数内可以让 `import app.api` 更快，也让
「没装 uvicorn 也能跑自检」成立。

### pydantic 2.14.1

| 模型 | 行号 | 字段 |
| --- | --- | --- |
| `ChatIn` | `app/api.py:143-146` | `question: str`、`mode: str = "rag"`、`k: int = K_DEFAULT` |
| `ParamsIn` | `app/api.py:159-161` | `mode: str \| None`、`k: int \| None` |

### python-multipart 0.0.32

`POST /api/docs/upload` 收 `files: list[UploadFile] = File(...)`，Starlette 需要这个库才能解析
`multipart/form-data`。**没装时的表现**是第一次上传直接 500，错误信息里明确写着
`Form data requires "python-multipart" to be installed`。

### starlette 1.10.0

FastAPI 的底座，本项目直接用到 `starlette.responses` 的三个响应类与 `starlette.staticfiles.StaticFiles`。

### 禁重定向的实现（两处一模一样，故意的）

```python
# app/llm.py:109 与 app/embedding.py:13
class _NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        return None      # 返回 None 表示不跟随，直接抛 HTTPError


def _no_redirect() -> urllib.request.OpenerDirector:
    return urllib.request.build_opener(_NoRedirect)
```

**为什么必须禁重定向**：接口地址是教师给的 HTTPS，请求头里带 `Authorization: Bearer <key>`。
默认 opener 会跟随 30x，把同一个请求（含密钥）重发到 `Location` 指定的任意地址。
`app/llm.py:117 _validate_endpoint` 已经强制 https 且禁 userinfo/query/fragment，
禁重定向是第二道闸。

## 四、HTTP 客户端行为约定（真实接口档）

`app/llm.py:132 call_model` 与 `app/embedding.py:86 _real_embed` 共享的错误语义：

| 情况 | 抛出的文案 |
| --- | --- |
| HTTP 4xx/5xx | `HTTP {code}，请按手册排查；本次未加入会话历史。` |
| 连接失败/超时 | `连接失败或超时：{exc}；本次未加入会话历史。` |
| 响应不是合法 JSON | `接口返回的不是合法 JSON，请检查 endpoint 是否为 Chat Completions 地址。` |
| `choices` 结构不符 | `接口返回结构不符合 Chat Completions 规范。` |

**「本次未加入会话历史」是刻意写进错误文案的**：`app/chat.py:43-66` 在 `llm.answer` 抛错时
只写一条 `status="error: ..."` 的日志，**不调用 `session.append_turn`**，所以失败的问答不会污染
下一轮的上下文。前端看到的红色气泡与这句话是一一对应的。

## 五、自检与依赖的关系

```powershell
py -3.12 -X utf8 tools\selfcheck.py            # 43 项，不需要 uvicorn、不需要 dist、不需要网络
py -3.12 -X utf8 tools\selfcheck.py --student  # 额外检查学生任务两处（本仓库已实现，同样通过）
```

`tools/selfcheck.py` 只 import `app` 包内的模块，**不 import `app.api`**，因此：
- 不需要 uvicorn；
- 不需要 `frontend/dist`（即使没构建过前端，自检照样 43/43）；
- 不需要任何密钥（mock 档自给自足）。

实测输出末行：`合计 43 项，通过 43 项，失败 0 项。全部通过。`

## 六、升级注意

| 依赖 | 升级风险 |
| --- | --- |
| fastapi 0.x → 0.y | `StaticFiles(check_dir=False)` 的 `check_dir` 参数从 0.60 起就有，短期安全；`File(...)` 的多文件写法在 0.100 前后有变，升级后须重跑上传用例 |
| pydantic 2.x → 3.x | `model_dump()` 与 `X \| None` 的写法可能有变，本项目 5 个模型都要复核 |
| uvicorn 0.5x | `uvicorn.run(app, host, port)` 签名稳定 |
| Python 3.10 → 3.13 | 无已知不兼容；`str \| None` 语法 3.10 起支持，3.9 会语法错误 |
