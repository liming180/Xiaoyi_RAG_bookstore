## 一、一句话概括

v2 是**三端架构**：前端 **Vue 3 + Vite 5 + TypeScript + Element Plus + Pinia**（`apps/web/`，已落地）；
Java 业务网关 **Spring Boot 3.2**（`backend/java-api/`，待建）；Python AI 服务 **FastAPI**（`backend/ai-api/`，待建）。
数据从「单个 `index.json` + 纯 Python 余弦暴力计算」升级为 **MySQL 8（业务数据）+ Milvus Lite（向量）**，
检索从「纯向量 top-k」升级为 **向量 + BM25 双路召回 → RRF 融合 → Rerank 重排**，并保留**离线 mock provider** 通道用于无密钥联调。

> 前端已按 （开发阶段文档，已完成并移除） 重写为 `apps/web/`（P1–P6 全部完成），
> 旧 `web/`（Vue 3 + 纯 JS，无 TS、无 UI 框架）已于 2026-11-01 删除。
> 后端按 `docs/02-重构设计/00_项目架构规格.md` 从 J0（契约冻结）开始重建。

| axios | ~~不引入，用 fetch~~ | **已引入**。全仓只有 `apps/web/src/api/http.ts` 一处 `import axios`，拦截器负责拆信封 + 401/503 广播 |
| TypeScript | ~~不引入~~ | **已引入**。strict + `vue-tsc` 门禁，类型手写在 `apps/web/src/types/api.d.ts` |
| playwright | ~~不引入~~ | **仍不引入**。改用 `apps/web/scripts/smoke.mjs` + `regress.mjs` 手写 CDP，零依赖 |
| Tailwind | ~~不引入~~ | **仍不引入**。改用 `apps/web/src/styles/tokens.css` 的 CSS 变量做双主题 |

| Celery / ARQ + Redis | — | **暂不引入**。任务队列用 FastAPI `BackgroundTasks` + 进程内任务表，Redis 列 P5 |
