# T00 技术栈总表

> **代码锚点**：`app/settings.py:10-24`（路径与常量）、`web/package.json`（前端依赖）、`app/api.py:291`（静态托管）
> **最后核对**：2026-10-30 实测（版本号取自 `importlib.metadata.version()` 与 `npm ls --depth=0`）

## 一、一句话概括

后端 **Python 3.12 + FastAPI**，前端 **Vue 3 + Vite 5**，数据落盘用 **单个 `index.json`**，
检索用 **纯 Python 暴力余弦**，模型通道有 **真实接口** 与 **离线 mock** 两档。
全项目**不引入向量数据库、不引入前端 UI 框架、不引入 TypeScript**，一共 5 个直接 Python 依赖 + 6 个前端依赖。

## 四、刻意不引入的依赖（每条都有理由）

| 候选 | 为什么不用 |
| --- | --- |
| **numpy** | 15 个片段、每个 256 维，纯 Python 的 `math.fsum` 循环耗时在毫秒级（`app/retrieval.py:10 cosine`）。加 numpy 只为了省几毫秒，却让「学生能逐行读懂余弦相似度」这个教学目标失效 |
| **FAISS / chroma / qdrant** | 同上；而且指导书任务4 要求「展示全部片段按得分降序 + 画出取回界线」，暴力全量打分反而是**正解**——向量库只返回 top-k，反而拿不到全量排名 |
| **streamlit / gradio** | 本机未安装；更关键的是任务3 要「两种回答并排」、任务4 要「表格里给第 k 行画虚线」、任务5 要「7 列表格 + 通过数统计」，这些用 Streamlit 的布局 API 拼不出来，只能退回 `st.markdown(unsafe_allow_html=True)`，反而更脏 |
| **requests** | 见上文「标准库」一节：`urllib` 的禁重定向 opener 是显式可控的 |
| **jieba 分词** | 嵌入是教师提供的接口，分词不参与检索；mock 通道用的是字符 n-gram（`app/embedding.py:58`），不需要词典 |
| **Pinia** | 全站只有一个 store（`web/src/store.js`，247 行），`reactive()` + 导出 `actions` 已经够用；加 Pinia 只是多一层 `defineStore` 包装 |
| **Vue Router** | 四个视图是同一个页面里的 tab（`v-show` 切换，`state.view`），没有 URL 需求，也没有深链接需求 |
| **Element Plus / Naive UI** | 视觉规范已按指导书示意图定稿（14 个 CSS 变量 + 16px 圆角 + 青绿主色），引 UI 框架会整体推翻配色与间距，验收截图就对不上了 |
| **Tailwind** | 同上；而且现有 4 个 css 文件（tokens/base/chat/table）已经把旧版 610 行样式 1:1 搬完 |
| **axios** | `fetch` 已在 `web/src/api.js` 封了 22 行，行为与旧版完全一致 |
| **TypeScript** | 项目没有类型体系，加 TS 要把 21 个 `.vue` + 5 个 `.js` 全部改写，收益是编辑器提示，成本是学生看不懂 |
| **playwright** | 只在本次迁移做浏览器验证时用过（`channel="chrome"` 复用本机 Chrome），**不是项目依赖**，不进 `package.json` |

## 五、两档模型通道

| 档位 | `config.json` 的 `provider` | 对话 | 嵌入 | 用途 |
| --- | --- | --- | --- | --- |
| 离线 mock | `"mock"`（默认，`app/settings.py:69 load_config` 文件缺失时即此档） | `app/llm.py:187 mock_answer` 按要点表从片段里抽句 | `app/embedding.py:58 mock_embed_one` 字符 n-gram 哈希 | 无网络/无密钥时演示与自检 |
| 真实接口 | `"real"` | `app/llm.py:132 call_model` 走 Chat Completions | `app/embedding.py:86 _real_embed` 走 embeddings | 接教师给的 HTTPS + Bearer |

两档共用同一套提示词、同一套检索、同一套来源标注，切换只改一个字段，
详见 `docs/03-后端设计/B06_离线模拟通道设计.md`。

## 六、运行环境要求

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | Windows 10+ / macOS 10.15+ | 指导书要求；本项目在 Windows 11 + PowerShell 7 实测 |
| Python | ≥ 3.10（推荐 3.12） | 代码用了 `X \| None` 联合类型语法，3.10 起支持 |
| node | ≥ 18（本机 21.7.1） | 只有**构建前端**时需要；构建产物 `web/dist` 已入库，纯运行不需要 node |
| 浏览器 | Chrome / Edge 近两年版本 | 用了 `scrollIntoView({behavior:'smooth'})` 与 `details/summary` |
| 端口 | 127.0.0.1:8765 | `config.json` 的 `port` 可改；`run.cmd` 与 `vite.config.js` 的代理都指向它 |
| 网络 | mock 档完全不需要 | real 档需要能访问教师给的 HTTPS 接口 |

## 七、启动路径速查

```bat
:: 纯运行（已有 dist）
run.cmd

:: 改了前端源码之后
cd web
npm run build
cd ..
run.cmd

:: 前端热更新开发（另开一个窗口跑 run.cmd 提供 /api）
cd web
npm run dev
```
