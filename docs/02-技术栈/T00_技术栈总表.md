# T00 技术栈总表

> **代码锚点**：`app/settings.py:10-24`（路径与常量）、`frontend/package.json`（前端依赖）、`app/api.py:292`（静态托管）
> **最后核对**：2026-11-01 实测（后端版本号取自 `importlib.metadata.version()`，前端取自 `frontend/node_modules/*/package.json`）

## 一、一句话概括

后端 **Python 3.12 + FastAPI**（v1 单体 `app/`）；前端 **Vue 3 + Vite 5 + TypeScript + Element Plus + Pinia**（`frontend/`）。
数据落盘用**单个 `index.json`**，检索用**纯 Python 余弦暴力计算**，模型通道有**真实接口**与**离线 mock** 两档。
后端一共 15 个直接 Python 依赖；前端 16 个运行时依赖 + 若干开发依赖，全部锁定精确版本。

> 前端已按 `docs/02-重构设计/03_前端开发提示词.md` 重写为 `frontend/`（P1–P6 全部完成），
> 旧 `web/`（Vue 3 + 纯 JS，无 TS、无 UI 框架）已于 2026-11-01 删除。本节只描述现行 `frontend/`。

## 六、启动速查

```bash
# v1 全栈（Python 单体 + 已构建的前端产物）
run.cmd

# v1 后端 only
py -3.12 -m uvicorn app.api:app --port 8765

# 前端开发（mock 模式，无需后端）
cd frontend && npm install && npm run dev

# 前端四道门禁（lint + typecheck + test + build）
cd frontend && npm run gate -- P6 --build

# 浏览器冒烟 / 全量回归
cd frontend && npm run smoke
cd frontend && npm run regress
```
