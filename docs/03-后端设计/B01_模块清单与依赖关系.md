**反向依赖是禁止的**：`store` 不 import `chat`，`chat` 不 import `api`。
这条约束的实际收益是 `tools/selfcheck.py` 可以只 import `store`/`chat`/`batch` 就把 43 项测完，
完全不需要起 HTTP 服务。

## 四、跨模块调用的三个关键契约

### 4.1 chunk 字典的字段是全局约定

```python
{
  "chunk_id": "D02-C001",     # D{资料序号:02d}-C{片段序号:03d}
  "source":   "02_借阅规则.md",
  "start":    0,              # 0-based，含
  "end":      180,            # 0-based，不含（end-start == len(text)）
  "text":     "# 星河读书会借阅规则\n\n本资料是……",
  "verified": True,           # source 不在 UNVERIFIED_SOURCES 里
  "embedding": [...],         # 仅 index.json 里有；对外一律剥掉
  "score":    0.8342,         # 检索后由 retrieval 补
  "rank":     1,              # 排名后由 rank_all 补
  "retrieved": True,          # split_trace 补，表示 rank <= k
}
```

`app/chunking.py:54 load_chunks` 产出前 6 个字段；`app/embedding.py:115` 补 `embedding`；
`app/retrieval.py:28 _scored` 补 `score`；`:42 rank_all` 补 `rank`；`:51 split_trace` 补 `retrieved`。
**任何模块都不许删字段**——`app/prompting.py:38 format_context` 依赖 `chunk_id`/`source`/`verified`/`text`。

### 4.2 `format_context` 的输出格式是全链路锚点

```
[D02-C001] 来源：02_借阅规则.md（正式规则）
# 星河读书会借阅规则

本资料是教学虚构规则。……

[D06-C002] 来源：06_成员留言摘录.md（⚠ 未经核实，仅供背景参考，不可作为结论依据）
留言2（成员代号"白榆"）：……
```

这段文本原样进入 `user` 消息的「参考资料：」块，也原样进入 JSONL 日志的 `messages` 字段。
**改了它，日志里的历史记录就对不上新格式**，所以格式一旦定稿不要再动。
