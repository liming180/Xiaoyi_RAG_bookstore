# F6 回答模式（查资料 / 不查资料 / 两者对照）

> 示意图定义：查资料、不查资料、两者对照。
> 对应任务3（20分）：对比"直接问模型"和"查资料再回答"，理解 RAG 在减少编造方面的作用。

## 前端（界面层）

- 模式三段切换按钮（rag / direct / both），当前项高亮；
- `both` 模式：同一问题**并排两张卡片**（左"不查资料"、右"查资料"），各带标签；查资料侧正常显示来源编号，不查资料侧显示醒目提示"**未引用知识库资料**"；
- 切换模式后**开始新会话**（骨架行为：`/mode` 会清空 history）—— 避免旧对话污染对照结果；
- 示意图提示语："两者对照 · 同一问题并排显示两种回答"。

**命令行版对应**：`/mode direct`、`/mode rag`，切换即新会话；对照=同一题问两遍（先 `/mode direct` 问一次，`/mode rag` `/new` 后再问一次）。

## 后端（逻辑层）

**关键区别只有一处：是否执行检索、是否把片段放进 user 消息。**

```python
if mode == "rag" or search_only:
    index = read_index(...)                      # 先校验库有效（F3）
    qvec  = embed_texts(cfg, embedding_key, [question])[0]   # 问题向量化（带缓存）
    hits  = select_top_k(index["chunks"], qvec, k)
else:
    hits = []                                    # direct：跳过检索，问题直接发给模型
messages = build_rag_messages(SYSTEM_PROMPT, history, question, hits)
answer, usage = call_model(cfg, chat_key, messages)
```

- 返回值带上 `used_knowledge_base: bool`，前端据此显示警告；
- direct 模式**不需要建库**（示意图注明"不查资料 · 无需建库"）；
- 检索失败（如待重建）不应阻塞 direct 模式。
