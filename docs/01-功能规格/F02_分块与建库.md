# F2 分块与建库

> 示意图定义：设置片段长度、重叠字数，显示进度和片段数量。
> 指导书：可设置片段长度和重叠字数（默认 180 和 30）；建库时把每个片段转为向量保存，并显示进度和片段数量。

## 前端（界面层）

- "分块设置"面板：**片段长度**（数字输入，50–1000，默认 180）、**重叠字数**（默认 30）；
- 校验规则前端先挡一层：`0 ≤ overlap < size`（骨架 `chunk_text` 会抛错兜底）；
- **重新建库**按钮 + 进度条（网页版轮询进度；命令行版打印"建库中…"即可）；
- 建库完成后显示摘要：**文档 N 份，片段 M 条**；
- 修改任一参数后未建库时，应显示 F3 的"待重建"提示。

## 后端（逻辑层）

### 1. 滑窗分块 — `chunk_text(text, size, overlap)`（骨架已实现）

```python
start = 0
while start < len(text):
    end = min(start + size, len(text))
    result.append((start, end, text[start:end]))   # 记录位置 → 拓展B要用
    if end == len(text): break
    start = end - overlap                           # 回退 overlap 字，形成重叠
```
- 相邻片段共享 overlap 个字符（验收拓展B：能看到重叠文字）；
- 参数非法（非整数 / overlap ≥ size）直接抛 `ModelError`。

### 2. 批量嵌入 — `embed_texts(cfg, key, texts)`（骨架已实现）

- 请求体：`{"model": embedding_model, "input": texts}`，Bearer 鉴权，禁止跟随重定向；
- **分批发送**：每批 `embedding_batch_size`（默认 8）条 —— 指导书常见问题：建库慢或报 413 就调小批量；
- 响应校验：`data` 数组长度一致、`index` 连续、向量维度统一、非全零、数值有限；
- 提问时对**问题本身**也调用同一接口得到查询向量（注意缓存同一问题的向量）。

### 3. 建库与持久化 — `build_index(cfg, key, data_dir, index_file)`（骨架已实现）

流程：校验配置 → 重算分块 → 分批嵌入 → 全量校验维度一致 → 写 `index.json`（先写临时文件再 `replace`，防止写坏旧库）。

**index.json 必须包含 manifest**（嵌入模型、接口、分块参数、各资料 SHA256）—— 这是 F3 状态判断和"换模型后旧向量不可用"防护的关键。

### 4. 拓展B 片段浏览（+5分）实现要点

片段自带 `start/end`（第几字至第几字）与重叠文本，前端按资料分组展示 + 关键词过滤（如搜"续借"），相邻片段原文展示即可看到重叠。

## 验收标准（表3）

| # | 操作 | 预期 |
|---|---|---|
| 1 | 180/30 建库 | ~15 个片段 |
| 2 | 长度改 120 重建 | 片段数增加 |
| 3 | 关闭程序重开 | **无需重建**可直接提问（index.json 已持久化） |

**易错点**：改了代码或 config.json 要重启程序；改了资料/分块/嵌入模型要重新 `/index`。
