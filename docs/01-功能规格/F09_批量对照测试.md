# F9 批量对照测试

> 示意图定义：批量运行题目，初判后仍需人工核对。
> 指导书（任务5，10分）：读入 questions.csv，每题两种模式各答一次，按判分关键词自动初判，统计两种模式通过数，结果保存为 CSV。

## 前端（界面层）

- "对照测试"Tab：
  - 顶部三个统计卡：**总题数 10 / 不查资料通过数 / 查资料通过数**；
  - "开始测试"按钮（批量运行期间禁用其他操作并显示进度）；
  - 结果表：每行 = 题号 | 类型（单文档/跨文档/库外）| 问题 | 不查资料回答+初判徽章 | 查资料回答+初判徽章；
  - 徽章两态：通过（绿色）/ 未通过（红色）；表内注明"初判结果，仍需人工核对"；
- 底部"导出 CSV"（网页版）或直接运行命令行版生成文件。

## 后端（逻辑层）

### 1. 读题

`questions.csv`（UTF-8 BOM，Excel 兼容），列：`编号,类型,问题,答案要点,证据文件`。**绝不放进 data/**。

### 2. 判分关键词规则（指导书原文，必须实现）

- 组间用 `|` 分隔，**每组都必须命中**；
- 组内用 `/` 分隔，**命中其一即可**；
- 例：`4本/四本|21天/二十一天` ⇒ 回答须含（"4本"或"四本"）**且**含（"21天"或"二十一天"）。

```python
def judge(answer, keywords):
    # keywords: "4本/四本|21天/二十一天"
    return all(any(alt in answer for alt in group.split("/"))
               for group in keywords.split("|"))
```

### 3. 批量执行

```
for 每道题:
    /new（清空会话）→ mode=direct 调用一轮 → 记录回答+初判
    /new → mode=rag 调用一轮（当前 k）    → 记录回答+初判
统计 passed_direct / passed_rag → 写结果 CSV
```

- 输出 CSV（UTF-8 BOM）：题号、类型、问题、direct回答、direct初判、rag回答、rag初判、rag来源片段 —— 即"对照测试结果表"提交材料；
- 复用 F4/F6 的问答函数，不要复制粘贴两套逻辑。

### 4. 预期结论（验收标准 2）

**查资料模式通过数明显高于不查资料模式**（11 道有答案题 rag 应全过；direct 对具体数字类题大概率编错；T09/T10 两道库外题 direct 会编造、rag 应答"未提供"）。

### 5. 人工核对（验收标准 3，写进报告）

关键词初判必有误差（如答"21 天"带空格、答"十六点"等）。报告中写明：抽了几题、用什么方法核对（对照来源片段原文逐条比对）、发现哪些误判并给出人工修正结论。**没有误判也要写明核对方法**。
