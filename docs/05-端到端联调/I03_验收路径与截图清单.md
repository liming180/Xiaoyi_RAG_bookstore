### 人工核对方法（报告必写）

1. **逐题读两列答案**，对 `答案要点` 列逐条打勾：要点里每个分句都在答案里出现了吗？
2. **看来源编号**：rag 答案每条结论后应有 `[Dxx-Cxxx]`；没有编号的结论视为「无依据」。
3. **抽查 3 题回原文**：点来源编号 → 展开 `<details>` → 用 Ctrl+F 在片段原文里找那个数字。推荐抽查 T03（4本/21天）、T07（16:00/4本）、T09（确认原文确实没写费用）。
4. **对初判「通过」但人工认为不对的**，在报告里单列「误判」小节；对初判「未通过」但人工认为对的，同样列出。
5. **记录核对人、核对时间、核对题数**，便于教师复现。

### 可复现的判定规则（`app/judging.py:11-22`）

```python
def judge(answer: str, keywords: str) -> bool:
    text = answer or ""
    return all(
        any(alt in text for alt in group.split("/"))
        for group in keywords.split("|")
    )
```

- 组间 `|`：**全部**必须命中
- 组内 `/`：命中**任意一个**即可
- 例：T03 `4本/四本|21天/二十一天` → 必须同时出现「4本或四本」与「21天或二十一天」
